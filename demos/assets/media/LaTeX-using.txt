# The Yoneda Lemma

I'm happy to explain the Yoneda lemma thoroughly.

## Setup

Let $\mathcal{C}$ be a locally small category. For each object $A \in \mathcal{C}$, we define the **representable presheaf**:

$$h_A = \mathrm{Hom}_{\mathcal{C}}(-, A) : \mathcal{C}^{op} \to \mathbf{Set}$$

This assigns to each object $X$ the set of morphisms $X \to A$.

## The Yoneda Lemma

For any presheaf $F: \mathcal{C}^{op} \to \mathbf{Set}$ and any object $A \in \mathcal{C}$:

$$\mathrm{Nat}(h_A, F) \cong F(A)$$

naturally in both $A$ and $F$. The bijection sends a natural transformation $\alpha: h_A \Rightarrow F$ to the element $\alpha_A(\mathrm{id}_A) \in F(A)$.

## Why It Matters

**1. The Yoneda Embedding is fully faithful.** Setting $F = h_B$:

$$\mathrm{Nat}(h_A, h_B) \cong \mathrm{Hom}_{\mathcal{C}}(A, B)$$

So the functor $y: \mathcal{C} \hookrightarrow [\mathcal{C}^{op}, \mathbf{Set}]$ defined by $A \mapsto h_A$ embeds $\mathcal{C}$ faithfully into its presheaf category.

**2. Objects are determined by their morphisms.** If $h_A \cong h_B$ as presheaves, then $A \cong B$. An object is completely characterized by how other objects map into it.

**3. "Generalized elements" viewpoint.** Elements of $F(A)$ can be thought of as "generalized elements of $F$ at stage $A$," and the Yoneda lemma says these correspond precisely to maps $h_A \to F$.

## Proof Sketch

Given $\alpha: h_A \Rightarrow F$, extract the element $\alpha_A(\mathrm{id}_A) \in F(A)$.

Conversely, given $x \in F(A)$, build a natural transformation: for any $f: X \to A$, define
$$\alpha_X(f) = F(f)(x) \in F(X)$$

Naturality follows from functoriality of $F$, and these constructions are mutually inverse.

## Connection to Bundles/Geometry

If you *were* thinking about bundles, the Yoneda perspective does appear naturally in:

- **Sheaf theory**: Presheaves are "pre-sheaves" (before the gluing condition), and representable functors detect local-to-global behavior.
- **Stacks and torsors**: Principal $G$-bundles on $X$ can be studied via the functor of points approach, where the Yoneda lemma identifies geometric objects with their functors.
- **Étalé spaces**: There is an equivalence between sheaves and étale bundles, with presheaves playing the "pre-bundle" role before sheafification.
